# Pulso
## Obtener el APK sin instalar nada (desde el móvil o PC)
1. Crea un repo en github.com y sube TODO el contenido de esta carpeta (incluida la carpeta oculta .github).
2. Pestaña Actions → "Build APK" → espera ~5 min (se lanza solo al subir).
3. Entra en la ejecución → Artifacts → descarga "pulso-apk" (zip con app-debug.apk).
4. Instala el APK en el Android (permitir "orígenes desconocidos").
## Con Android Studio
Open → carpeta Pulso → Build > Build APK(s) → app/build/outputs/apk/debug/app-debug.apk
